## 🛠 Что нужно для запуска

1. **Python** (версии 3.10 или новее). Если его нет, скачайте с официального сайта python.org.
2. **Установленная библиотека Flet**.

---

## 🚀 Как запустить проект

Выполните эти 3 простых шага в терминале (командной строке) внутри папки с проектом:

### Шаг 1. Откройте терминал в папке с проектом
* **На Windows:** Зайдите в папку с проектом, зажмите клавишу `Shift`, кликните правой кнопкой мыши по пустому месту и выберите *"Открыть окно PowerShell"* или *"Открыть командную строку"*.
* **На Mac/Linux:** Откройте Терминал и перейдите в папку командой `cd /путь/к/папке`.

### Шаг 2. Установите Flet
Введите команду и нажмите Enter:
```bash
pip install -r requirements.txt
```

### Шаг 3. Запустите приложение
Введите команду для запуска главного файла:
```bash
python code/main.py
```

## 📊 Примеры работы приложения

* **Что вводить (Вход):** Пользователь запускает программу, перед ним открывается графическое окно. В поля ввода нужно вписать (например: *числа / текст / выбрать файл*).
* **Что получается (Выход):** После нажатия на главную кнопку приложение выводит результат прямо на экран (например: *считает сумму / показывает график / выводит сообщение*).
